# Прототип Теготеки

Репозиторий для создания локально запускаемого браузерного прототипа и проверки концепции и интерфейса Теготеки. Данные сохраняются между запусками.

## С чего начать

1. Прочитать [задание на прототип](prototype/TASK.md).
2. Изучить [корневую концепцию](PRODUCT_CONCEPT.md) и [проверочные сценарии](prototype/CHECKS.md).
3. Выбрать и кратко описать технологии и существенные решения реализации.
4. Реализовать прототип, проверить его и передать результат по условиям задания.

Задание независимо от инструмента или модели исполнителя. Репозитории вариантов начинают с одинаковых документов и истории; каждая реализация развивается самостоятельно.

## Исходное состояние

Задание и сценарии зафиксированы коммитом `f8291b3`; корневая концепция для задания — состоянием `8dfed9e`. Эти коммиты сохранены в истории репозитория.

В исходном состоянии находятся документы. Код, инструкция запуска и отчёт о проверках должны появиться в ходе выполнения задания. Настоящий README следует дополнить инструкцией запуска по мере готовности приложения.

Документы концептуальной разработки, расширений и методологии сохранены как контекст. Объём работы исполнителя определяется [заданием](prototype/TASK.md).
