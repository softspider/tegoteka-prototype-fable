# Самостоятельные глоссарии тегов

**Статус:** необязательное расширение.

**Родительский модуль:** [базовый продукт](../PRODUCT_CONCEPT.md).

**Обязательная зависимость:** базовый продукт и текущий набор тегов рабочей области.

Расширение подчиняется [соглашениям продукта с расширениями](../PRODUCT_EXTENSION_AGREEMENTS.md#общие-соглашения).

## Назначение

**Самостоятельный глоссарий тегов** — набор тегов, который можно создавать и выбирать для использования в разных рабочих областях. Пользователь может создать такой глоссарий, выбрать существующий или использовать глоссарий по умолчанию.

Глоссарий тегов рабочей области формируется при разметке элементов. Это расширение описывает самостоятельные глоссарии; все дальнейшие правила этого документа относятся к ним.

Глоссарий может формироваться постепенно, начиная с пустого или небольшого набора тегов и пополняясь при разметке элементов. Такой способ особенно полезен в начале работы с продуктом.

## Различение глоссариев

При использовании в разных рабочих областях и переносе без изменений глоссарий считается тем же. Один и тот же глоссарий автоматически распознаётся в разных рабочих областях.

Добавление нового тега создаёт другой глоссарий по отношению к исходному. Для различения глоссариев история их изменения не требуется.

**Полный глоссарий** — глоссарий, содержащий все теги выбранного глоссария независимо от их использования в рассматриваемых элементах.

**Сокращённый глоссарий** — глоссарий, содержащий только теги исходного глоссария, использованные в заданном наборе элементов. Он считается самостоятельным глоссарием, отличным от исходного.

## Взаимодействие с базовым продуктом

Расширение предоставляет теги выбранного глоссария для использования в рабочей области. Применение этих тегов к текущему набору рабочей области описано в [документе координации](../coordination/TAG_GLOSSARY.md).
