# Расширения и их координация

[Соглашения продукта с расширениями](../PRODUCT_EXTENSION_AGREEMENTS.md).

## Расширения

Родительским модулем перечисленных ниже расширений является базовый продукт.

| Необязательное расширение | Обязательная зависимость |
| --- | --- |
| [Самостоятельные глоссарии тегов](TAG_GLOSSARY.md) | Базовый продукт и текущий набор тегов рабочей области. |
| [Импорт и экспорт](IMPORT_EXPORT.md) | Базовый продукт, включая ручную разметку и список неразмеченных элементов. |
| [Автоматическая разметка с помощью большой языковой модели (LLM)](LLM_ANNOTATION.md) | Базовый продукт и его правила разметки. |
| [Поиск по тексту внутри текущей выборки](TEXT_SEARCH.md) | Базовый продукт и текущая теговая выборка. |

[Сочетание разных видов содержания](MIXED_CONTENT.md) рассматривается как потенциальное расширение. Его правила требуют отдельного определения.

## Координация

Документы координации определяют правила взаимодействия конкретных расширений, условия их применения и необходимые зависимости в рамках общих соглашений родительских модулей.

- [Координация работы с самостоятельными глоссариями тегов](../coordination/TAG_GLOSSARY.md).
- [Координация импорта, экспорта и самостоятельных глоссариев](../coordination/IMPORT_EXPORT_TAG_GLOSSARY.md).
- [Координация импорта и автоматической разметки](../coordination/IMPORT_LLM_ANNOTATION.md).
