# Поиск по тексту внутри текущей выборки

**Статус:** необязательное расширение.

**Родительский модуль:** [базовый продукт](../PRODUCT_CONCEPT.md).

**Обязательная зависимость:** базовый продукт и текущая теговая выборка.

**Дополнительное взаимодействие:** взаимодействие с другими расширениями не определено.

Расширение подчиняется [соглашениям продукта с расширениями](../PRODUCT_EXTENSION_AGREEMENTS.md#общие-соглашения).

## Назначение и границы

Расширение позволяет искать элементы по словам их текстового содержания внутри текущей теговой выборки, в том числе по словам, которые не являются тегами.
