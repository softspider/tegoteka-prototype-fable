# Модель расширений и общие соглашения

Документ описывает общую модель иерархических расширений и правила их взаимодействия с родительскими модулями. Модель предназначена для применения в разных продуктах.

## Модель и зависимости

**Расширение** — дополнение к возможностям корневого продукта или другого расширения.

**Родительский модуль расширения** — корневой продукт или другое расширение, возможности которого оно дополняет.

**Обязательная зависимость** — модуль, без которого расширение не может работать.

**Дополнительное взаимодействие** — совместная возможность расширений, доступная при наличии необходимых для неё модулей.

Подключение расширения добавляет описанные в его документе возможности.

Родительский модуль может работать без своего расширения. Расширение требует наличия родительского модуля и может иметь другие обязательные зависимости, явно указанные в его документе. Наличие зависимости от другого расширения само по себе не делает его родительским модулем.

## Общие соглашения

Расширение опирается на положения, определения и соглашения родительского модуля, включая унаследованные от вышестоящих модулей. Оно сохраняет смысл используемых понятий и соблюдает применимые правила.

Расширение может определять дополнительные соглашения для собственных расширений с соблюдением соглашений своего родителя.
