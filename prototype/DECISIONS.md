# Решения реализации прототипа

Документ фиксирует выбор исполнителя в пределах [задания](TASK.md). Определения и правила берутся из [корневой концепции](../PRODUCT_CONCEPT.md); здесь описано только то, что концепция оставляет реализации.

## Технологии

| Часть | Решение |
| --- | --- |
| Запуск | Локальный сервер на Node.js 20+ без устанавливаемых зависимостей: `npm start` или `node server/server.mjs`. Сервер слушает только `127.0.0.1`. |
| Интерфейс | Одностраничное приложение на ES-модулях без шага сборки. Отрисовка — Preact + htm; единственный сторонний файл хранится в `public/vendor/`. |
| Модель | Чистые функции в `shared/`: одни и те же модули исполняются сервером, браузером и автоматическими проверками. |
| Хранение | Каталог на диске (по умолчанию `data/`). У каждой рабочей области — `workspace.json` (элементы, теги, описания), `state.json` (последний узел, история, режим, сортировка, настройки) и каталог `files/` с самими файлами содержания. |
| Проверки | Правила модели — `node --test`; сценарии в браузере — Playwright (Chromium) на временном каталоге данных и отдельном порту. |

Отбор, соседство и автодополнение вычисляются в браузере по загруженной рабочей области. Каждое изменение данных — одна операция на сервере: она применяется целиком либо не применяется, после чего сохраняется на диск.

## Вычисление узлов

Комбинации тегов не перечисляются. Узел задаётся набором тегов; заполненные узлы получаются группировкой размеченных элементов по точному набору тегов. Для текущего узла соседние заполненные потомки — минимальные по включению заполненные надмножества, соседние заполненные предки — максимальные по включению заполненные подмножества. Наборы сравниваются битовыми масками.

## Допущения

**Различение тегов.** Тег — строка без пробелов, запятых и точек с запятой, не длиннее 64 знаков. Регистр не различается: название приводится к нижнему регистру. Пробелы внутри названия при переименовании заменяются на `_`. При вводе нескольких тегов разделителями служат пробел, запятая и точка с запятой. Внутри данных тег имеет постоянный идентификатор, поэтому переименование не затрагивает назначения.

**Порядок тегов.** Набор тегов не упорядочен. Разметка элемента показывается в порядке ввода, текущий узел — в порядке выбора тегов, изменяемые теги в обозначении перехода — по алфавиту.

**Порядок при равном приоритете.** Переходы с одинаковым числом изменяемых тегов упорядочиваются по убыванию размера выборки узла назначения, затем по алфавиту обозначения.

**Компактный набор переходов.** По умолчанию показываются шесть наиболее приоритетных переходов в каждом направлении. Остальные раскрываются по запросу; для потомков при большом числе вариантов добавляются фильтр по тегу и постраничный просмотр.

**Автодополнение.** При навигации предлагаются ещё не выбранные теги элементов текущей выборки: сначала совпадающие с начала названия, затем содержащие введённый текст; при равенстве — по убыванию частоты в выборке. Точное название любого тега рабочей области принимается и без подсказки — так задаётся произвольный узел. При разметке предлагаются все теги рабочей области.

**Замена элемента.** Элемент различается идентификатором, а не содержанием. Изменение названия или тегов сохраняет идентификатор; изменение содержания создаёт новый идентификатор, а прежняя запись удаляется. Время последнего изменения новой записи — время замены.

**Удаление тега и время изменения.** Удаление тега меняет разметку затронутых элементов, поэтому обновляет их время последнего изменения; взаимный порядок этих элементов сохраняется. Переименование тега разметку не меняет и время не обновляет.

**История при удалении тега.** Текущее посещение заменяется узлом с оставшимися тегами. Другие посещения, содержащие удалённый тег, остаются в истории на своих местах, но становятся недоступными и пропускаются при движении назад и вперёд.

**Сохранение состояния просмотра.** Вместе с последним узлом между запусками сохраняются история переходов, режим просмотра, сортировка и настройки. Они хранятся отдельно для каждой рабочей области.

**Содержание.** Вид файла определяется по MIME-типу: `image/*` показывается как изображение, `audio/*` и `video/*` воспроизводятся встроенным проигрывателем браузера, остальные файлы открываются в новой вкладке или скачиваются. Если браузер не поддерживает формат, вместо просмотра показывается ссылка на файл. Размер файла ограничен 200 МБ. Текст из одних пробелов сохраняется как пустое содержание.

## Средства проверки

Несколько рабочих областей и их создание из заготовок — средство проверки прототипа, а не часть продуктовой модели. Заготовки: пустая область, демонстрационный набор E0–E9, тот же набор с примерами медиа, диагностический набор на 10 000 элементов.
